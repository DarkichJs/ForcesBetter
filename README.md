# ForcesBetter

Chrome-расширение, которое делает Codeforces приятнее: тёмная тема в духе eolymp,
скруглённые углы, аккуратные отступы, шрифт Geist, примеры ввода/вывода карточками рядом.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. «Загрузить распакованное» → выберите эту папку.

Настройки — в popup расширения: тема (светлая / тёмная / авто), акцентный цвет,
скругление, шрифт, широкая страница. Тему также можно переключать кнопкой в шапке сайта.

Шрифт Geist распространяется по лицензии SIL OFL 1.1 (`fonts/OFL.txt`).
